未浏览






  

    

      
      

        

      

        

      
      
      点击「截图」获取手机当前屏幕
    

    

      截图由手机 root 执行 screencap，等比缩放到指定宽度后以 JPEG 回传（约 80~200KB），
      原图保存在手机 DE 缓存目录。屏幕熄灭时通常只能拍到黑屏，可先到「状态」页点「唤醒」。

      点击「拍照」由手机摄像头直接拍摄（无需亮屏）
    

    

      拍照使用系统相机硬件（Camera2）在后台直接拍摄；本地会另存一份到
      /sdcard/DCIM/S20Remote。缺权限时自动用 root 授权；仍不可用则拉起系统相机 App 人工拍摄。
    

  

  

    
暂无照片

  

  

    

      
      
      

        

      录音由手机麦克风采集，AAC 编码（1~86400 秒，最长 24 小时）
    

    

      录音命令立即返回、后台录制：开始后本页每 2 秒轮询进度，可随时点「停止」提前结束；
      完成后文件保存在 /sdcard/Music/S20Remote 并可点击下载。屏幕锁定时开始录音会先自动解锁（约 5-10 秒）。

唤醒 / 解锁

    

      

      

    

    

      解锁方式与开机脚本一致：点亮 → 上滑 → 输入 PIN，最多 3 轮。PIN 明文存于设备保护(DE)区，
      接口不回显明文；持有 token 的人点「唤醒」即可解锁屏幕。

      修改 PIN 会同时写入 magisk 开机脚本（/data/adb/modules/s20remote/service.sh 的 UNLOCK_PIN 行），
      下次开机即用新 PIN 自动解锁；保存后操作记录会显示同步结果。

      说明：检查在手机本地独立运行，不依赖中转连接，因此 WiFi 被关闭导致中转断开后仍能自动恢复。
